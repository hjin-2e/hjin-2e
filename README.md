### 👋 안녕하세요, 안정적이고 확장 가능한 인프라를 지향하는 이하진입니다.

- ☁️ **AWS / Azure** 기반의 멀티 클라우드 환경 구축 및 IaC(**Terraform**) 코드화를 즐겨합니다.
- 🛠️ **DevOps & Infrastructure**: EKS/Kubernetes, Docker, CI/CD 파이프라인 자동화 및 모니터링 구축 경험이 있습니다.
- 💻 **Frontend Integration**: React, Vue, HTML/CSS, TypeScript 환경의 웹 애플리케이션 개발 경험을 바탕으로 프론트엔드와 클라우드 인프라 간의 매끄러운 연동을 이해합니다.
- ✍️ 배운 내용과 트러블슈팅 과정을 정리하며 기록하는 습관을 가지고 있습니다.
